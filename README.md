# Tic-Tac-Toe Game

A simple Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

## Features
- Two-player game (Player X and Player O)
- Interactive game board
- Winner detection
- Draw detection
- Reset game option
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript
